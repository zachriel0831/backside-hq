HQ 系統升級 .NET 10｜改動點與風險

  • 升級範圍：HQ 員工入口、舊後台及 Web API 現行為 .NET Framework 4.6.1；HQBackSite 新後台及其測試為 4.7.2。兩個網站都依賴 System.Web，須移植到 ASP.NET Core 10，並將測試專案改為 net10.0。Microsoft 移植指南
  • 盤點範圍：截至 2026-11-11，已核對原始碼、專案與發布設定。兩站 NuGet 清單分別有 34、41 筆，合計 54 種不同套件，另有 3 個測試套件。正式站組態、歷史附件及 .NET 10 執行結果尚待驗證。

必須替換或升級的套件

  • MVC 與 Razor：兩站的 Microsoft.AspNet.Mvc 5.2.4／5.2.7、Microsoft.AspNet.Razor 與 Microsoft.AspNet.WebPages 3.2.4／3.2.7、對應 zh-Hant 語系包，改用 ASP.NET Core 10 共用框架及 Razor SDK。表單驗證的繁中訊息需一併驗收。
  • HQ Web API：Microsoft.AspNet.WebApi 5.2.4 及 Core、WebHost、Client、HelpPage、對應語系包移出舊管線。控制器改用 Core MVC，原 API 說明頁如仍供使用，需保留入口或提供替代文件。Microsoft Web API 移植指南
  • 編譯、打包與追蹤：移除 Microsoft.CodeDom.Providers.DotNetCompilerPlatform 2.0.0／2.0.1、Microsoft.Web.Infrastructure 1.0.0.0。以靜態資源取代 Microsoft.AspNet.Web.Optimization 1.1.3 及語系包、WebGrease 1.6.0、Antlr 3.5.0.2；HQ 的 Microsoft.AspNet.TelemetryCorrelation 1.0.0 若需延續請求追蹤，改接 Core 診斷管線。
  • PDF 連結擷取：HQ 的 iTextSharp 5.5.13.3 僅提供 .NET Framework 組件，並依賴 BouncyCastle 1.8.9。換用支援現代 .NET 的 PDF 函式庫，例如 itext，依選定套件確認授權及加密相依。以實際公文分別核對 PDF 超連結註解與純文字網址，避免漏列附件。舊套件 · 替代套件與授權
  • HTML 解析與 JSON：AngleSharp 1.1.2 升至含已知修補的 1.5.0 以上相容版。兩站 Newtonsoft.Json 11.0.1／12.0.2 亦有已知公告；若保留既有 JSON 格式，統一採修補的 13.x，使用 Core MVC 整合時配 Microsoft.AspNetCore.Mvc.NewtonsoftJson 10.0.x 並滿足其相依下限。AngleSharp 修補紀錄 · Json.NET 公告 · Core 整合套件
  • SQL Server 驅動：兩站使用 Framework 內建 System.Data.SqlClient，移植時須明列驅動。建議採 Microsoft.Data.SqlClient；新版預設要求加密，若主機名或憑證信任鏈不符，入口、員工查詢與電子報可能同時無法連線。Microsoft 加密與憑證規則

可沿用或解除舊版鎖定的套件

  • 後台資料、日誌與登入：Dapper 2.1.66、NLog 4.7.15、System.IdentityModel.Tokens.Jwt 與 Microsoft.IdentityModel.* 8.15.0 已有相容資產，可先沿用版本。將 NLog 寫檔、輪替與篩選設定遷出舊 Web.config；JWT 的 Tokens、JsonWebTokens、Logging、Abstractions 由同一版系解析。Dapper · NLog · JWT
  • Active Directory：System.DirectoryServices 已列 10.0.2，後台專案仍引用 Framework 組件。保留 AD 時改為套件引用，並以 Windows 站台身分驗證網域連通及密碼驗證流程。支援平台
  • 基礎相依：重新解析 System.Buffers、System.Memory、System.Numerics.Vectors、System.Runtime.CompilerServices.Unsafe、System.Diagnostics.DiagnosticSource、System.Threading.Tasks.Extensions、System.ValueTuple、System.Text.Json、System.Text.Encodings.Web、System.Text.Encoding.CodePages。以 .NET 10 提供的組件為準，僅保留程式或相依套件仍需要的引用。
  • 其他間接相依：Microsoft.Bcl.AsyncInterfaces、Microsoft.Bcl.TimeProvider、Microsoft.Extensions.Logging.Abstractions、System.IO.FileSystem.AccessControl、System.Security.AccessControl、System.Security.Principal.Windows 同步解除 Framework 時代的版本鎖定；保留 AD 時核對 Windows 相依。
  • 前端套件：jQuery、Bootstrap、Modernizr 2.8.3、jQuery.Validation 1.17.0、Microsoft.jQuery.Unobtrusive.Validation 3.2.11 可與 .NET 分開升級。HQ 使用 Bootstrap 3.3.7，jQuery 宣告 3.3.1、主 bundle 對應檔為 1.9.1；新後台使用 jQuery 3.4.1，Bootstrap 宣告 3.4.1、實檔為 5.3.3。按清單重裝會改變選單、表單或版型。
  • 編輯器與外部資源：新後台編輯頁使用 CDN 的 CKEditor 4.22.1，另載入 AJAX 外掛與圖示。CKEditor 4 開源版已停止維護，續用支援版或更換編輯器須另估授權及內容相容性。驗收內網載入、舊文章格式、貼圖與儲存。原廠支援與授權

HQ 員工入口、舊後台與 API

  • 啟動與路由：將 Global.asax、App_Start、全域例外處理移入 Program.cs。3 個業務 MVC、10 個 Web API 控制器須保留首頁 /Hq/Index、舊後台及 /api/{controller}/{action}/{id?}；明訂部門頁既有 POST、清快取的 GET／POST，避免舊網址回 404 或 405。
  • API 格式：10 個前端業務腳本直接讀取 res.Table。改用 ControllerBase 與 Core 回應型別，保留表名大小寫、空資料及數值回傳；啟用自動模型驗證時須核對 HTTP 400 與既有錯誤格式。Core 預設 JSON 沒有 DataSet 轉換器，直接切換會使清單失效。Microsoft 型別支援
  • 舊後台登入：FormsAuthenticationTicket 改為 Core Cookie 與帳號 Claim。程式實際簽發 30 分鐘、非持久票證；核對切換時重登、到期、登出、6 個受保護頁面，以及新增公告記錄的建立者。
  • 舊編輯器上傳：將 UEditor 的 controller.ashx 與 8 個支援類別改成 Core 端點，保留原網址、欄位及回應。涵蓋設定、圖片／塗鴉／影片／檔案上傳、圖檔清單、檔案清單及遠端圖片擷取；沿用原檔案存取限制，解除對獨立 Newtonsoft.Json DLL 的引用。Microsoft Handler 移植指南
  • 外部公文與快取：保留 HTML／PDF 下載的 20 秒逾時、重新導向後的相對連結與電子報預覽／正式網址。將 System.Runtime.Caching 的 5 組快取移至 IMemoryCache 等相容實作，維持活動 3 小時、其餘 12 小時與手動清除；若採多執行個體，單機清除會留下舊內容。
  • 頁面與舊網址：HQ 有 20 個網站 Razor 檔、19 個 API 說明頁 Razor 檔。替換 Scripts.Render、Styles.Render，保留腳本順序、站根資源、附件及連往外部 .aspx 頁面的網址。傳真及餐廳有 CP950 靜態 HTML，對應 Razor 檔為 UTF-8 且宣告 Big5，須分別驗中文顯示。

HQBackSite 新後台

  • 登入與權限｜高風險：現行登入未呼叫 AD 密碼比對，登入時的權限查詢回傳固定非空清單，部分內容查詢在無明細權限時會擴大範圍。切換前須確認正式身分來源及部門授權，以有效／無效帳密、無權與跨部門帳戶驗證登入、直接進頁及寫入操作。
  • 登入狀態：移植 Authorization JWT Cookie、帳號 Claim、一天效期及登出；簽章金鑰移至受控設定，決定舊 Cookie 延續或統一重登。本機登入例外不可因反向代理而套用到一般使用者。保留頁面轉登入、AJAX 回 code=-1；Core 10 的 Cookie 驗證對已識別 API 預設回 401／403。Microsoft 驗證行為
  • 管理頁與表單：新後台有 31 個 Razor 檔，MenuController 有 44 個回傳 ActionResult 的方法。2 個子動作改為頁內元件；替換 Html.Action、Ajax.BeginForm。分別處理 JSON、表單及 multipart 綁定，保留部分頁更新、code/message/data、camelCase 與日期 yyyy-MM-dd HH:mm:ss。
  • 內容、公告與 ICS：驗收選單授權、部門分類、內容與跑馬燈修改後能在 HQ 正確顯示。ICS 將表單內 JSON 分寫 news 與 ics_list，現行多次寫入未共用交易；須處理中途失敗，核對切換類別後明細新增、更新及軟刪除結果。
  • 附件與 Word：以 IFormFile 與明確的儲存目錄取代 Request.Files、Server.MapPath。一般上傳程式上限 50 MiB，Word 僅收 .docx、上限 20 MiB；IIS、應用主機及表單上限均須容納 multipart 開銷，否則合法檔案會在進入程式前遭拒。Microsoft 上傳限制
  • Word 預覽：轉換器採內建 ZIP/XML，可保留。原始 Word 須維持私有，產出 HTML 由授權預覽端點讀取；保留圖片網址、表格合併與 PDF 連結改寫，非法檔名或缺檔回 404。切換網域時一併核對編輯器內的兩站網址。

資料庫、發布與驗收風險

  • 共用 SQL 與設定：兩站將 ConfigurationManager 改接環境設定，保留主資料庫、EP 員工庫、電子報、測試連線與跨庫查詢的分工。升級本身未發現必須變動資料表的項目；以同一筆後台異動核對前台讀回，並驗 SQL 權限、預覽網址與繁中日期。
  • IIS 與發布：兩個網站改用 Web SDK、PackageReference 與 .NET 10 發布流程。Framework 相依部署須確認 Windows Server 支援、安裝 .NET 10 Hosting Bundle 並配置 ASP.NET Core Module。以 wwwroot 或指定目錄供應靜態檔，確認原 /images 目錄瀏覽的保留範圍。重設反向代理的 HTTPS／主機名、錯誤頁與操作／例外日誌；檢查日誌可寫、輪替與敏感欄位遮蔽。Microsoft IIS 部署
  • 歷史附件｜高風險：HQ 現有發布設定會清除目的目錄；專案宣告的發布內容有 74 筆未隨本次盤點檔案提供，含圖片、附件與編輯器 DLL。切換前比對正式站、備份並將使用者上傳與 Word 成品存放於發布目錄以外；以舊文章網址、重新發布及回復演練確認可讀。
  • 測試與建置：測試移除 MVC 5、Razor、WebPages DLL 與 HttpContextBase 模擬，調整 Microsoft.NET.Test.Sdk 17.11.1 及 MSTest.TestAdapter／TestFramework 3.5.2 至支援目標的組合。現有 34 個測試限於後台內容、ICS、Word；需補兩站登入／拒絕、前台 API、真實 SQL、上傳與 IIS 發布後回歸。測試套件狀態
