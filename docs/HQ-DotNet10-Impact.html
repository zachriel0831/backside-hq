HQ 系統升級 .NET 10｜改動點與風險

  • 升級範圍　HQ 員工入口、舊後台與 Web API 使用 .NET Framework 4.6.1，HQBackSite 新後台與測試使用 4.7.2。兩站移植至 ASP.NET Core 10 時須替換 System.Web 網站管線。測試專案直接參考新後台，須提供相容的測試目標。Microsoft 移植指南
  • 盤點範圍　截至 2026-11-11，兩站套件清單分別有 34、41 筆，按名稱去重為 54 種，測試專案另有 3 種。以下依現行程式與官方相容性資料判定，正式站設定、歷史檔案及移植後的執行結果待驗。

必須替換或升級的套件

  • MVC 與 Razor　兩站的 Microsoft.AspNet.Mvc 5.2.4／5.2.7、Microsoft.AspNet.Razor 與 Microsoft.AspNet.WebPages 3.2.4／3.2.7、對應 zh-Hant 語系包，改用 ASP.NET Core 10 共用框架及 Razor SDK。表單驗證的繁中訊息需一併驗收。
  • HQ Web API　Microsoft.AspNet.WebApi 5.2.4、Core、WebHost、HelpPage 及對應語系包依賴舊伺服器管線。控制器改以 Core 的回應型別傳回資料與狀態。若仍提供 API 說明頁，保留 /Help 入口或改接替代文件。Client 5.2.4 有 .NET Standard 2.0 資產，僅在仍使用其用戶端格式化功能時保留。Client 目標框架
  • 編譯、打包與追蹤　移除 Microsoft.CodeDom.Providers.DotNetCompilerPlatform 2.0.0／2.0.1、Microsoft.Web.Infrastructure 1.0.0.0。以靜態資源取代 Microsoft.AspNet.Web.Optimization 1.1.3 及語系包、WebGrease 1.6.0、Antlr 3.5.0.2；HQ 的 Microsoft.AspNet.TelemetryCorrelation 1.0.0 若需延續請求追蹤，改接 Core 診斷管線。
  • PDF 連結擷取　iTextSharp 5.5.13.3 僅提供 .NET Framework 組件，依賴的 BouncyCastle 1.8.9 已停止維護。可改採支援文字與連結註解的 PdfPig（Apache-2.0），或依授權條件採用新版 iText（AGPLv3／商業授權）。舊套件 · PdfPig 功能與授權 · iText 授權
  • HTML 解析　HQ 用 AngleSharp 1.1.2 解析外部公文。原廠公告指出 1.0.0 至 1.8.1 處理特定 HTML 時可能大量耗用 CPU；此問題自 1.8.2 起修補，選版時應涵蓋該修補。AngleSharp 安全公告
  • JSON　兩站使用的 Newtonsoft.Json 11.0.1／12.0.2 皆有安全公告。若沿用 Json.NET，選用已修補且符合整合套件下限的 13.x。ASP.NET Core MVC 的 NewtonsoftJson 10.0.0 要求至少 13.0.3，其他 10.0.x 依所選版本確認。Json.NET 公告 · MVC 相依版本
  • SQL Server 驅動　兩站現用 Framework 內建 System.Data.SqlClient。其同名 NuGet 不受 Microsoft 在 .NET 9 以上支援；.NET 10 應改採 Microsoft.Data.SqlClient。逐庫比對 SQL Server 版本、驅動支援矩陣及加密預設值，確認主機名稱與憑證鏈後再切換。舊驅動支援公告 · 驅動支援矩陣 · 憑證規則

可沿用或解除舊版鎖定的套件

  • 後台資料、日誌與登入　Dapper 2.1.66、NLog 4.7.15、System.IdentityModel.Tokens.Jwt 與 Microsoft.IdentityModel.* 8.15.0 已有相容資產，可先保留並於 .NET 10 驗收。將 NLog 寫檔、輪替與篩選設定接至新站；JWT 的 Tokens、JsonWebTokens、Logging、Abstractions 由同一版系解析。Dapper · NLog · JWT
  • Active Directory　新後台清單有 System.DirectoryServices 10.0.2，專案實際引用 Framework 組件。若正式登入選用 AD 驗密，改為套件引用，部署於受支援的 Windows 主機，驗證網域連通、站台身分及有效／錯誤密碼。Microsoft 平台實作
  • 基礎相依　重新解析 System.Buffers、System.Memory、System.Numerics.Vectors、System.Runtime.CompilerServices.Unsafe、System.Diagnostics.DiagnosticSource、System.Threading.Tasks.Extensions、System.ValueTuple、System.Text.Json、System.Text.Encodings.Web、System.Text.Encoding.CodePages。以 .NET 10 提供的組件為準，僅保留程式或相依套件仍需要的引用。
  • 其他間接相依　Microsoft.Bcl.AsyncInterfaces、Microsoft.Bcl.TimeProvider、Microsoft.Extensions.Logging.Abstractions、System.IO.FileSystem.AccessControl、System.Security.AccessControl、System.Security.Principal.Windows 同步解除 Framework 時代的版本鎖定；保留 AD 時核對 Windows 相依。
  • HQ 前端　Bootstrap 3.3.7 已停止維護。jQuery 清單列 3.3.1，主要頁面實檔為 1.9.1；首頁與舊後台各一處使用 jQuery 3 已移除的 .load(handler)。更新 jQuery 須同步改綁 load 事件，核對電話查詢、輪播與側選單。UEditor 1.4.3 部分對話框另載 jQuery 1.10.2。jQuery 事件變更 · Bootstrap 3 維護狀態
  • 新後台前端　實檔為 jQuery 3.4.1、Bootstrap 5.3.3，Bootstrap 套件清單卻列 3.4.1。兩站的 jQuery 更新另需納入 3.5.0 起的安全修補。Modernizr 2.8.3、jQuery.Validation 1.17.0 及 Microsoft.jQuery.Unobtrusive.Validation 3.2.11 可與 .NET 分開處理，按實際頁面載入情形保留。jQuery 安全修補
  • 編輯器與外部資源　新後台編輯頁使用 CDN 的 CKEditor 4.22.1，版面另載入 jquery-ajax-unobtrusive 3.2.6 與 Font Awesome 6.4.0。CKEditor 4 開源版已停止維護；續用支援版或換版時，核對授權、內網載入、舊文章格式、貼圖及儲存。原廠支援與授權

HQ 員工入口、舊後台與 API

  • 啟動與路由　將 Global.asax、App_Start 及全域例外處理移入 Core 啟動管線。保留 3 個業務 MVC、10 個 Web API 控制器的首頁 /Hq/Index、舊後台、/api/{controller}/{action}/{id?}，以及清快取既有的 GET／POST。新後台根網址另對應 Home/Index。
  • 部門頁書籤與查詢　舊書籤 /Hq/Dept?分店代碼 使用無欄位名稱的查詢字串。頁籤 POST TabsPage?id=… 從網址取 id；內容 POST PageContent 從 JSON 本文取 dept。移植時明訂參數來源，以同一分店核對頁籤及內容。Microsoft API 綁定規則
  • API 回應　10 個業務腳本直接讀 res.Table；舊後台同一列混用 Page、Dept、subtype。System.Text.Json 沒有內建 DataSet 轉換器；可用相容序列化設定或明確回傳原欄位。核對大小寫、空表、數值及錯誤狀態，尤其是自動驗證傳回的 HTTP 400。Microsoft 型別支援
  • 舊後台登入與寫入　舊後台比對資料庫帳密後，簽發 30 分鐘、非持久的 FormsAuthentication 票證。改用 Core Cookie 時須保留建立者身分，核對到期、登出及切換時重登。6 個管理頁有登入保護；寫入 API 與清快取未見同等應用層授權，須另確認正式 IIS 限制並驗證未授權操作會遭拒。
  • 舊編輯器上傳　以 Core 端點接手 UEditor 的 controller.ashx 與 8 個支援類別，解除獨立 Newtonsoft.Json DLL 引用。保留設定、圖片／塗鴉／影片／附件、清單及遠端抓圖所用的網址、欄位與回應。一般檔案、Base64 塗鴉與遠端圖片的現行檢查不同，須逐類限制來源、大小及型別，核對舊文章的 /ueditor/net/upload/ 連結。Microsoft Handler 移植指南
  • 外部公文　下載保留 20 秒逾時，核對可信來源、TLS 與重導後來源。PDF 的 original_html 實為全文文字，附件優先取 URI 連結註解，無結果才從文字補抓符合 PDF 副檔名的網址；用重導後網址解析相對路徑，核對繁中文件、檔名、去重及順序。
  • 電子報　分店公文合併新舊來源，少一個來源仍可能回 HTTP 200；TestingMode 缺值預設為真，須分別核對兩種來源的正式連結。
  • 快取　HQ 有 5 組快取，部門活動保留 3 小時，其餘 12 小時。可用 System.Runtime.Caching 相容套件沿用，或改用 IMemoryCache。兩者均為單機記憶體；部署多個站台執行個體時，手動清除須涵蓋所有執行個體。Microsoft 快取選項
  • 頁面與舊網址　HQ 有 20 個網站 Razor 檔、19 個 API 說明頁 Razor 檔。替換 Scripts.Render、Styles.Render，保留腳本順序、站根資源、附件及外部 .aspx 網址。若 IIS 改掛虛擬路徑，須逐一檢查從站根起算的 API 與圖片連結。傳真及餐廳有 CP950 靜態 HTML，對應 Razor 檔為 UTF-8 且宣告 Big5，須分別驗中文顯示。

HQBackSite 新後台

  • 登入與員工身分｜高風險　新後台簽發 Cookie 前檢查帳號格式與密碼非空；登入流程未呼叫 AD 比對密碼，且權限查詢回傳固定非空清單。一般受保護請求另驗 JWT 並查 EP 員工庫，查無員工或查詢失敗即拒絕。正式身分來源、無效帳密、離職或無權帳戶及 EP 中斷要分別驗證。
  • 選單與部門權限｜高風險　選單權限 API 輸出 code/data/menuCodes，側欄腳本卻讀 Code/Data/MenuCodes。部分內容查詢在沒有明細權限時會擴大範圍。須統一欄位，分別驗證側欄顯示、直接進頁、跨部門讀寫與權限撤銷。
  • 登入狀態　保留 Authorization JWT Cookie、HttpOnly、Account 身分欄位、一天效期與零寬限。使用 Core 的 Bearer 處理器時須指定從 Cookie 取值，並核對驗證後的 token 型別。簽章金鑰改由受控設定提供，確認切換時的重登策略、HTTPS 與登出範圍。本機登入例外須避免在代理後誤套用。Microsoft 權杖型別變更
  • 登入逾時　現行頁面轉登入，帶 AJAX 標頭的請求讀取 code=-1。部分上傳使用未帶該標頭的 fetch；共用請求另會先將非 2xx 視為錯誤。若採 Core 10 Cookie 驗證，其已識別 API 預設回 401／403，須同步處理畫面提示與重新登入。Microsoft 驗證行為
  • 管理頁與表單　新後台有 31 個 Razor 檔，MenuController 有 44 個回傳 ActionResult 的方法。2 個子動作須換用 Core 支援的呈現方式，例如檢視元件；替換 Html.Action、Ajax.BeginForm。分別處理 JSON、表單及 multipart 綁定，保留部分頁更新、code/message/data、camelCase 與日期 yyyy-MM-dd HH:mm:ss。使用 Cookie 的寫入表單與 AJAX 須配對防偽權杖及伺服器驗證。
  • 內容、公告與 ICS　核對選單、部門內容與跑馬燈修改後的前台讀回。ICS 新增／修改畫面傳 JSON，其中 icsSecurityData、icsIsoData 是 JSON 字串；伺服器另接受表單，附件獨立走 multipart。應依內容類型取值，避免對 JSON 讀取 Request.Form。Microsoft 表單讀取規則
  • ICS 資料一致性　主檔 news 與明細 ics_list 分次寫入，未共用交易；編輯另讀 ics_upload。核對類別切換、明細更新與軟刪除、附件舊連結及中途失敗後的回復，並比對 HQ 前台清單。
  • 附件與大小上限　一般上傳的程式上限為 50 MiB，Word 僅收 .docx、上限 20 MiB。以 IFormFile 與明確儲存目錄取代 Request.Files、Server.MapPath。IIS、應用主機與表單上限須容納 multipart 開銷；以接近上限的檔案驗證。一般附件保留原副檔名，須限制允許類型，確認上傳目錄無執行權，且代理後的下載網址正確。Microsoft 上傳限制
  • Word 預覽　轉換器採內建 ZIP/XML，可保留。原始 Word 須維持私有，產出 HTML 由授權預覽端點讀取；保留圖片網址、表格合併與 PDF 連結改寫，非法檔名或缺檔回 404。切換網域時一併核對編輯器內的兩站網址。

資料庫、發布與驗收風險

  • 共用 SQL 與設定　正式路徑使用主資料庫、EP 員工庫、電子報及跨庫查詢；測試連線另依環境設定。ConfigurationManager 可用相容套件過渡，或改用 Core 組態；須逐一對應有效設定與機密來源。未見升級必改的資料表。驗 SQL 權限、動態查詢參數與表名限制，以及同筆後台異動的前台讀回。組態相容套件
  • 建置與 IIS　兩站改用 Web SDK、PackageReference 與相容的 .NET SDK，移除舊組件繫結重新導向與重複的專案檔案宣告。使用 Visual Studio 建置 net10.0 時，官方支援 18.0 起。逐台核對 Windows Server 支援狀態。IIS 需 ASP.NET Core Module；框架相依部署還需 .NET 10 與 ASP.NET Core 共用執行階段，自含式部署自帶執行階段。採 in-process 時兩站各用獨立應用程式集區，位元架構須相符。建置版本 · 作業系統 · IIS 模組 · 集區條件
  • 靜態檔與正式設定　建置時已知的 CSS、腳本與圖片可用 MapStaticAssets；上線後新增的公開附件須另設靜態檔服務或下載端點，保留原網址。確認 /images 目錄瀏覽範圍、代理後的 HTTPS 與主機名稱、繁中日期、錯誤頁及日誌寫入／輪替。正式錯誤回應應隱藏例外堆疊；操作與資料庫日誌須遮蔽敏感查詢值與 SQL 參數。Microsoft 靜態檔規則
  • 歷史附件｜高風險　HQ 的資料夾發布設定會清除目的目錄；宣告內容有 74 筆缺少對應檔案（images 39、userfiles 32、UEditor 3）。切換前須與正式站比對並備份，將上傳與 Word 成品放在發布目錄之外。重新發布及回復後，各以舊文章附件、剛上傳的檔案與授權 Word 預覽核對。
  • 回歸測試　現有 34 個測試限於後台內容、ICS 與 Word。將 MVC 5、Razor、WebPages DLL 及 HttpContextBase 模擬改接新後台。現用 Microsoft.NET.Test.Sdk 17.11.1 與 MSTest.TestAdapter／TestFramework 3.5.2；後兩者已標記停止維護，應選可在目標環境探索並執行測試的版本。另補兩站登入與拒絕、前台 API、真實 SQL、上傳及 IIS 發布後回歸。MSTest 套件狀態
