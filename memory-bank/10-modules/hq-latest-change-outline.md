## 3. 功能變更

### Word 轉 HTML

- 後台可上傳 `.docx`，上限 20 MB。
- 解析文字、表格與圖片後產生 HTML。
- HTML 放在 `Views/GeneratedHtml`，圖片放在 `images/word-html`。
- 提供預覽 Action，並新增對應測試。

### 選單權限

- 新增 `t_menu_resource` 與 `t_user_menu_permission` 的管理流程。
- 登入後依使用者權限產生選單。
- 目前主要控制選單顯示，尚未完整限制 Controller Action。

### ICS 與消息

- 新版後台增加 ICS 名單與附件管理。
- HQ 員工入口增加 ICS 內容與跑馬燈讀取。
- 修正欄位別名、軟刪除回復與局部 DOM 更新。

### 中文編碼

- `HQ/itMember.html` 已補正 UTF-8 宣告。
- 此修改對應先前頁面中文亂碼畫面。

## 4. 工程變更

- 新增 `HQBackSite.Tests`，涵蓋 Word HTML、Content 與 ICS 的部分流程。
- 新增操作紀錄與全域例外 Filter。
- 建立 `memory-bank` 的模組、逐檔分析、RAG 索引與程式碼索引。
- 為 HQ 與 HQBackSite 增加專案級 `.gitignore`，避免交付本機資料、Log 與產生檔。

## 5. 部署影響

| 項目 | 是否需處理 | 說明 |
|---|---|---|
| 資料庫 | 是 | 選單權限需 `t_menu_resource`、`t_user_menu_permission`；ICS 需相關資料表與欄位 |
| IIS 寫入權限 | 是 | Word 上傳、HTML 與圖片輸出目錄需寫入權限 |
| 設定檔 | 是 | 檢查 Connection String、JWT、本機登入除錯設定 |
| 前端快取 | 建議 | `itMember.html` 編碼與 JavaScript 更新後應清除快取驗證 |
| 自動化測試 | 是 | 至少建置方案並執行 `HQBackSite.Tests` |
| HQ API 回歸 | 是 | 現有自動化覆蓋不足，需人工驗證首頁、文章、消息、ICS |
